# Social Media Algo Website

This website a simplified educational representation and does not reproduce the proprietary systems used by actual social media companies.  

It includes these features:  
- Behavioural Tracking: How your viewing activity is recorded.  
- Interest Scoring: How different interactions contribute to topic scores.   
- Dynamic Recommendations: How your feed changes as your interests are inferred.  
- Filter Bubble Detection: How concentrated your recommended content becomes.   
- Algorithm Report: A summary of the interests and patterns identified during your session.   

The website was written in python using streamlit. Claude was used to assist in areas where we did not know the syntax or features completely, such as customising the elements with html.
